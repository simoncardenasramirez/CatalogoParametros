# Integración de Parámetros

Entrega para los equipos del semillero. Leer [la guía PDF](Guia-integracion-Parametros.pdf) o [la versión editable](Guia-integracion-Parametros.md).

- [Excel para Seguridad: 92 recursos protegidos](recursos-parametros.xlsx).
- [Excel alternativo: solo 17 recursos del microfrontend](recursos-parametros-microfrontend.xlsx). Ya están incluidos en el Excel completo; no importar ambos.
- [Inventario de las 93 operaciones](Endpoints-Parametros.csv), con autenticación y alcance de carga.
- [Colección Postman completa](Parametros.postman_collection.json).

Los Excel conservan la hoja Recursos y los tres encabezados de la plantilla del componente de Seguridad. El nombre de aplicación es Catalogo; cambiarlo si el servicio se registró con otro nombre. Validar antes de confirmar la carga y asignar los recursos a roles/usuarios después de importar.

La lectura por token se incluye en el inventario y Postman; se excluye del Excel porque valida su propio Bearer y omite PEP. Las rutas técnicas se documentan en el anexo G. La entrega no importa datos ni concede permisos automáticamente.
